# Daniel Khisa — personal portfolio

**Live site:** [dankhisa.github.io](https://dankhisa.github.io/)

A personal portfolio connecting audit, risk, regulation and governance with
practical tool-building. The featured project is the
[Bermuda Compliance Navigator](https://dankhisa.github.io/bermuda-compliance-navigator/).

## Technology

One HTML file with embedded CSS, system fonts and an inline SVG favicon. No
JavaScript, build step, external fonts, analytics, forms or backend. GitHub Pages
hosts the site from the `main` branch at the repository root.

## Updating the site

1. Open `index.html` in this repository and choose the edit/pencil action.
2. Find the text to update and preserve the surrounding HTML tags.
3. Commit the change to `main` with a short descriptive message.
4. Wait for Pages deployment, then refresh the site and check both wide and
   narrow browser layouts. Editing takes minutes; deployment can take longer.

## Scope

This is an independent personal portfolio. Projects are educational
demonstrations, not professional advice or employer/regulatory endorsements.
The portfolio links to public work and its source code on GitHub.
